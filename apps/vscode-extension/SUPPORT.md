# LLMatic Agent Runtime Support

## Before reporting a problem

Run these commands from the VS Code Command Palette:

```text
LLMatic: Show Status
LLMatic: Doctor
```

If the runtime integrity check fails, also run:

```text
LLMatic: Repair Runtime
```

If Kilo Code or MCP registration is the problem:

```text
LLMatic: Connect Kilo Code Globally
```

## Bug reports

Open an issue at:

https://github.com/pikkst/llmatic-agent-runtime/issues

Include:

- LLMatic version
- VS Code version
- operating system
- whether the extension came from Marketplace or a VSIX
- the relevant LLMatic output-channel diagnostics
- exact reproduction steps
- expected and actual behavior

Do not include API keys, credentials, private source code, or other secrets.

## Security-sensitive reports

Do not post credentials or exploitable private details in a public issue. If the repository later adds a dedicated private security-reporting channel, use that channel for sensitive reports.
